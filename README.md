# vibe-todo

터미널에서 쓰는 간단한 할 일 관리 프로그램입니다.
메뉴에서 번호를 골라 할 일을 추가하고, 완료 표시를 하고, 지우고, 검색할 수 있습니다.
할 일 목록은 파일에 저장되므로 프로그램을 껐다 켜도 그대로 남아 있습니다.

```
          할 일 목록
┏━━━━━━┳━━━━━━━━┳━━━━━━━━━━━━━┓
┃ 번호 ┃  상태  ┃ 할 일       ┃
┡━━━━━━╇━━━━━━━━╇━━━━━━━━━━━━━┩
│    1 │ 미완료 │ 우유 사기   │
│    2 │  완료  │ 숙제 하기   │
└──────┴────────┴─────────────┘
```

## 기능

| 메뉴 | 하는 일 |
|---|---|
| 1. 목록 보기 | 할 일을 번호 / 상태 / 할 일 표로 보여 줍니다. 완료한 일은 상태가 초록색으로 표시됩니다. |
| 2. 추가 | 제목을 입력해 새 할 일을 추가합니다. |
| 3. 완료 | 번호를 골라 할 일을 완료로 바꿉니다. |
| 4. 삭제 | 번호를 골라 할 일을 지웁니다. |
| 5. 종료 | 프로그램을 끝냅니다. |
| 6. 검색 | 검색어가 제목에 들어간 할 일만 보여 줍니다. 영어는 대소문자를 구분하지 않습니다. 결과의 번호는 전체 목록 번호와 같아서, 그 번호로 바로 완료·삭제할 수 있습니다. |

- 할 일을 추가·완료·삭제하면 바로 `todos.json` 파일에 저장됩니다.
- 숫자가 아닌 값이나 없는 번호를 입력해도 안내만 보여 주고 계속 동작합니다.

## 설치와 실행

이 프로젝트는 [uv](https://docs.astral.sh/uv/)로 파이썬과 패키지를 관리합니다.

### 1. uv 설치

이미 설치되어 있다면 건너뛰세요.

```bash
# macOS / Linux
curl -LsSf https://astral.sh/uv/install.sh | sh

# Windows (PowerShell)
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

### 2. 코드 내려받기

```bash
git clone https://github.com/eomjinyoung/vibe-todo.git
cd vibe-todo
```

### 3. 실행

```bash
uv run main.py
```

처음 실행하면 uv가 알아서 다음을 준비합니다. 따로 설치 명령을 칠 필요가 없습니다.

- `.python-version`에 적힌 파이썬(3.15)이 없으면 내려받습니다.
- `.venv` 폴더(가상환경)를 만들고, `uv.lock`에 적힌 버전 그대로 패키지(`rich`)를 설치합니다.

미리 설치만 해 두고 싶다면 `uv sync`를 실행하면 됩니다.

## 데이터 저장

할 일 목록은 `main.py`와 같은 폴더의 `todos.json`에 저장됩니다. 파일이 없으면 빈 목록으로 시작합니다.

```json
[
  {
    "title": "우유 사기",
    "done": false
  }
]
```

`todos.json`은 개인 데이터라서 `.gitignore`에 넣어 Git에 올라가지 않게 했습니다.

## 사용한 기술

- Python 3.13 이상
- [uv](https://docs.astral.sh/uv/): 파이썬 버전과 패키지 관리
- [rich](https://github.com/Textualize/rich): 터미널 표와 색깔 출력
